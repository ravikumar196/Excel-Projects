# 📊 Advanced Microsoft Excel Corporate Analytics Portfolio

Welcome to my Excel Analytics repository. This portfolio is designed to showcase enterprise-level data engineering, analytical modeling, and visual dashboard development using Microsoft Excel. 

Rather than relying on basic static charts, these projects leverage advanced Excel frameworks—including **Power Query (M Language)** for automated ETL pipelines, **Power Pivot** for dimensional data modeling, and complex formulas to drive real-world business decisions.

---

## 📈 Featured Excel Dashboards

### 1. Corporate Sales Performance Dashboard
* **Business Use Case:** Designed for regional sales managers to track monthly revenue targets, evaluate product category profit margins, and identify underperforming sales lanes.
* **Core Features:** Automated multi-sheet data combining via Power Query, dynamic date filtering tables, and KPI trend cards.
* **Key Metric Uncovered:** Identified that a **4.5% margin leak** in the logistics layer was wiping out the profits of top-selling electronics.
* **👉 [Explore the Sales Project & Files](./Sales-Dashboard/)**

### 2. HR Turnover & Workforce Analytics Suite
* **Business Use Case:** Built for HR Executives to monitor employee attrition rates, analyze salary equity across departments, and map tenure trends.
* **Core Features:** Advanced logical modeling, conditional variance matrices, and interactive slicers linked across multiple pivot caches.
* **Key Metric Uncovered:** Pinpointed that departments with over-allocation on weekend overtime experienced a **28% spike** in attrition.
* **👉 [Explore the HR Project & Files](./HR-Dashboard/)**

### 3. Corporate Finance & Budget Variance Model
* **Business Use Case:** Provides the CFO with a live visual tool to map actual expenditures against projected departmental budgets.
* **Core Features:** Power Pivot Data Modeling, complex DAX formulas (CALCULATE, RELATED), and conditional trend alerts.
* **👉 [Explore the Finance Project & Files](./Finance-Dashboard/)**

### 4. Dynamic Inventory Control & Supply Chain Matrix
* **Business Use Case:** Streamlines warehouse operations by tracking stockout frequencies, safety stock levels, and vendor lead times.
* **Core Features:** Automated re-order warning systems using complex nested logical array formulas (`INDEX`, `MATCH`, `LET`, `LAMBDA`).
* **👉 [Explore the Inventory Project & Files](./Inventory-Dashboard/)**

## 🛠️ Core Excel Skill Matrix Demonstrated

* **Data Engineering (ETL):** Cleaning messy text datasets, splitting unformatted columns, flattening nested JSON/CSV strings, and building repeatable data loading systems using **Power Query**.
* **Data Modeling:** Creating structured relational structures inside **Power Pivot**, establishing 1-to-many relationships, and organizing data into clean Star Schemas.
* **Analytical Formulations:** Mastery of advanced array formulas (`XLOOKUP`, `INDEX/MATCH`, `LET`, `SUMPRODUCT`, `FILTER`, `UNIQUE`).
* **Visual Engineering & Design:** Developing professional UI layouts using customized color palettes, strict grid alignment, locked grid sheets, and dynamic slicers for intuitive navigation.
